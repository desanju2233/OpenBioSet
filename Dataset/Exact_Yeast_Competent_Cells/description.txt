Protocol details:

ASSAY TYPE: EXACT-Ontology-Formalized Yeast Competent-Cell Culture Growth Protocol ("Grow Yeast Culture" Operating Procedure, Table 3 / Figure 3)

REAGENTS/OBJECTS USED:
  - YPD Media Bottle (Yeast extract, Peptone, Adenine hemisulfate, Dextrose medium, 50 ml used)
  - Sealed Yeast Colonies Plate (single yeast colony, small volume used for inoculation)
  - 500 ml Conical Flask (renamed to "YPD conical flask", then to "yeast culture flask" as its state changes)
  - Equipment: pipette (medium transfer), inoculating loop (colony transfer), shaking incubator (200 rpm, 30 C)

STEPS (as formalized in EXACT / Figure 3 Haskell representation):
1. Move (12): YPD media bottle, start location = store, end location = laminar flow hood.
2. Move (13): 500 ml conical flask, start location = store, end location = laminar flow hood.
3. Move (14): sealed yeast colonies plate, start location = cold room, end location = laminar flow hood.
4. Add (15): component = YPD medium, volume = 50 ml, from YPD media bottle into the 500 ml conical flask, using a pipette.
5. Rename (16): 500 ml conical flask -> "YPD conical flask".
6. Add (17): component = single yeast colony, volume = small volume, from the sealed yeast colonies plate into the YPD conical flask, using an inoculating loop.
7. Rename (18): YPD conical flask -> "yeast culture flask".
8. Move (19): yeast culture flask, start location = laminar flow hood, end location = incubator.
9. Incubate (20): yeast culture flask in a shaking incubator, 200 rpm, 30 C, for 12-24 h, goal = grow yeast until the medium becomes cloudy.

Post-condition: yeast culture located_in incubator.

INTERPRETATION: Successful execution of the operating procedure is confirmed by the stated post-condition (yeast culture located in the incubator) and by the growth goal being met, i.e. the medium becoming visibly cloudy after 12-24 h of shaking incubation at 30 C, indicating a viable, actively growing yeast culture ready for downstream use (e.g. as the starting culture for a competent-cells preparation). The paper uses this excerpt to illustrate how EXACT's formalized experiment-action vocabulary (move, add, rename, incubate, with fully specified parameters) removes the ambiguity present in the original natural-language protocol from Methods in Yeast Genetics (e.g., unclear shaking speed, unclear duration of "overnight").
