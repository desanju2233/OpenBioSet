PROTOCOL DESCRIPTION
====================

Title        : An Automated Induction Microfluidics System for Synthetic Biology
Source Link  : https://www.shihmicrolab.ca/_files/ugd/f0a828_dff8587cf80c488aa25077207e571507.pdf
Paper DOI    : http://dx.doi.org/10.1021/acssynbio.8b00025
Journal      : ACS Synthetic Biology, 2018, Vol. 7, pp. 933-944
Platform     : Digital microfluidics (DMF) with integrated 600 nm LED absorbance reader,
               TSL2561 lux sensor, Arduino Uno controller, and MATLAB-based GUI automation


OVERVIEW
--------
This protocol describes the Automated Induction Microfluidics System (AIMS), a digital
microfluidic platform for automating bacterial cell culture, OD-triggered IPTG induction,
and on-chip protein expression analysis without manual intervention. The system integrates:
  (1) A DMF device for droplet-based cell culture, induction, and enzymatic assays
  (2) A 600 nm LED + TSL2561 lux sensor for real-time OD monitoring at 280 um gap height
  (3) An Arduino Uno + MATLAB GUI for automated droplet movement and induction triggering
  (4) CLARIOStar plate reader for end-point fluorescence detection (off-chip)

Three protocols are encoded sequentially in the BioScript file:
  P1 - Growth Curve: Semicontinuous mixing of E. coli mother culture with OD monitoring
       until the induction threshold (OD = 0.4) is reached.
  P2 - Inducer Concentration Optimisation: On-chip 2:1 serial dilution of IPTG to generate
       a dose-response curve for RFP expression using a pET16b-RFP reporter construct.
  P3A - BGL Single-Point Screening: Three thermophilic beta-glucosidases (BGL1: T. roseum,
        BGL2: T. terrenum, BGL3: R. marinus) screened for MUG hydrolysis activity after
        4 h induction; time-course fluorescence assay (0, 15, 30, 45, 60 min).
  P3B - BGL3 Multi-Point Optimisation: BGL3 (highest activity, >=6x BGL1/BGL2) optimised
        across five post-induction incubation times (0, 2, 3, 5, 6 h); fixed 30 min MUG
        assay per time point.

Volume reduction: 10,000x in culture (15 uL vs 150 mL); 40x in assay (5 uL vs 200 uL).
Hands-on time at 5-plex: 18 min (AIMS) vs 35 min (bench-top).
IPTG cost at 5-plex: $0.01 reagents (AIMS) vs $2.52 reagents (bench-top).


DEVICE ARCHITECTURE
-------------------
Substrate     : Chromium electrodes patterned on glass (S1811 photoresist, Telic Valencia CA)
                Mask resolution: 25,400 dpi (CAD/Art services)
Dielectric    : Parylene-C, 7.2 um thick (SCS Labcoter 2 PDS 2010, Specialty Coating Systems)
Hydrophobic   : FluoroPel PFC1601 V (Cytonix, Beltsville MD); spin-coated 1500 rpm 30 s,
coating         500 rpm/s acceleration; baked 180 C 10 min (Laurell spin coater)
Top plate     : ITO-coated glass (RS = 15-25 Ohm, Delta Technologies CG-61IN-S207)
Gap height    : 280 um (chosen; tested: 210, 280, 350 um)
Design tool   : AutoCAD 2016 (Autodesk)
Fabrication   : Concordia Silicon Microfabrication Lab (ConSIM)

Device sections:
  - Mother culture area: 4 x 4.5x4.5 mm square electrodes
  - Absorbance reading electrode: small middle square 2 (electrode 4); transparent window
    0.25 mm; slope = 0.998, R^2 = 0.999; limit of detection = 0.029 OD units
  - Reservoirs: LB media, IPTG, lysis solution, MUG substrate, stop solution, waste
  - 5 assay/incubation areas
  - 32 actuation electrodes total

Absorbance window selection (7 electrodes tested):
  Electrode 4 (small middle square 2) chosen: reliable droplet movement, slope 0.998,
  R^2 = 0.999. Electrode 1 (large middle square) failed: droplet movement unreliable.
  Star/central/spaced arrays showed non-linear OD response due to small transparent regions.

AIMS hardware:
  LED           : 600 nm (Digikey cat no. 1497-1021-ND); 8 mm above device
  Lux sensor    : TSL2561 (Adafruit); 4 mm below device
  Controller    : Arduino Uno
  Relays        : AQW216 Panasonic (Digikey, Winnipeg MB)
  Function gen. : 33201A Agilent (Allied Electronics, Ottawa ON)
  Amplifier     : PZD-700A Trek Inc. (Lockport NY); delivers 130-270 Vrms sinusoidal
  Communication : I2C protocol (Maxim 7300 I/O expander, Digikey)
  Enclosure     : 3D printed PLA top cover and bottom holder
  Software      : MATLAB (GUI) + Arduino firmware (available at github.com/shihmicrolab/AIMS)


ORGANISM AND STRAINS
--------------------
Host          : E. coli BL21(DE3) (donated by Dr. Vincent Martin, Concordia University)
Vector        : pET16b (T7 promoter + lacI coding sequence)
Reporter      : RFP (BBa_E1010, iGEM registry); cloned via XbaI/BamHI into pET16b
BGL enzymes   :
  BGL1 - Thermomicrobium roseum        (accession YP_002522957.1; synthesised by IDT)
  BGL2 - Thermobaculum terrenum        (accession WP_041425608.1; synthesised by Gen9/Ginkgo)
  BGL3 - Rhodothermus marinus DSM4252  (accession WP_012844561.1; synthesised by Gen9/Ginkgo)
  All BGL genes cloned via XbaI/BamHI into pET16b; transformed into BL21(DE3)
Selection     : LB agar + 100 ug/mL ampicillin (37 C overnight)


REAGENTS
--------
Culture media       : LB broth + 100 ug/mL ampicillin
Anti-biofouling     : 0.05% Pluronics F-68 (added to all cell-containing droplets;
                      prevents protein/cell adsorption on DMF device surfaces)
IPTG stock (P2)     : 3.24 mM; 0.3 uL per dispensed droplet
IPTG stock (P3)     : 11 mM; 2 uL per induction event
Lysis buffer        : 1x (BugBuster-based); 1.42 uL per assay droplet; 10 min RT
MUG substrate       : 6 mM 4-methylumbelliferyl beta-D-glucopyranoside (Carbosynth EM05983)
                      in 150 mM sodium-citrate; 1.42 uL per assay droplet
Stop solution       : 0.4 M glycine-NaOH; 1.42 uL per assay droplet
OD blank            : LB media + 0.05% F-68, no cells (I0 reference reading)
Restriction enzymes : XbaI, BamHI (Thermo, Waltham MA)
Ligase              : T4 ligase (Thermo, Waltham MA); 1 h at RT
Polymerase          : Phusion; 10 uL 5X buffer, 1 uL DMSO, 200 uM dNTPs, 0.5 uM primers,
                      0.5 uL enzyme; PCR: 98 C 30s; 35x (98 C 10s, 55 C 30s, 72 C 30s/kb);
                      72 C 10 min final extension


OD MEASUREMENT
--------------
Formula      : A = log(I0 / I) / 0.028
               A  = absorbance (OD units)
               I0 = blank lux intensity (LB media, no cells)
               I  = sample lux intensity
               0.028 = path length correction factor for 280 um gap height
Threshold    : OD = 0.4 (triggers IPTG induction)
LOD          : 0.035 OD units (at 280 um gap height)
Mixing cycle : one actuation every 45 s; 700 ms actuation time; horizontal + vertical
               4-step sequence; prevents biofouling while maintaining cell homogeneity
Re-check     : If OD < 0.4, continue mixing for 10 min before next OD measurement
Doubling time: AIMS: 72.88 +/- 2.30 min; bench-top: 36.80 +/- 0.36 min
               (two-tailed paired t-test; P = 0.018)
               Difference attributed to semicontinuous vs continuous mixing efficiency
               and shorter path length (280 um vs 1 cm)


PROTOCOL STEPS
--------------

Step 1 | Device Preparation and Blank Acquisition
  Reagents  : LB_Media, PluronicF68
  Operation : mix, 30 s
  Purpose   : Dispense blank droplet (LB + 0.05% F-68, no cells) to acquire I0 lux reading.
              Device inserted into AIMS slot: 8 mm below LED, 4 mm above lux sensor.
              Alignment marks on device and bottom holder used to centre absorbance window
              on lux sensor and minimise lux measurement fluctuations.

Step 2 | Mother Culture Loading
  Organism  : E. coli BL21(DE3) [pET16b]
  Starting OD : 0.1 (overnight culture diluted in LB + 0.05% F-68)
  Volume    : 14 uL loaded onto mother culture area (4 x 4.5x4.5 mm electrodes)
  Operation : mix, 30 s
  Setup     : Bottom plate mated with ITO top plate (grounding). Device placed in incubator
              at 37 C with open water container for humidity; prevents droplet evaporation.

Step 3 | Semicontinuous Mixing and OD Monitoring (P1)
  Mixing    : One actuation every 45 s; 700 ms actuation time; horizontal + vertical
              4-step movement sequence. Continuous mixing caused biofouling within 2 h;
              700 ms actuation time is the minimum for reliable movement without biofouling.
  OD check  : Every 10 min; mother droplet extended to absorbance window electrode.
              If OD < 0.4: return to mixing area; wait 10 min; re-measure.
              If OD >= 0.4: trigger induction program.
  Detection : odMeasurement module; 10 s read duration.
  IR note   : 600 s (10 min) mixing encoded in bsbbif_3_f fail branch.

Step 4 | IPTG Serial Dilution Preparation (P2)
  IPTG stock : 3.24 mM; 0.3 uL per droplet
  Culture    : 1.42 uL unit droplets of RFP-transformed BL21(DE3)
  Method     : 2:1 serial dilution on-chip; explicit dispense + mix steps (no split)
  Concentrations : 200, 133.3, 88.9, 59.3, 40, 26.7, 17.8, 11.9 uM
  Assay spots : 5 (matching device 5-plex layout)
  Macroscale : 45 mL culture induced at 200 uM; diluted with fresh media for series;
               200 uL loaded onto 96-well plate; triplicates + noninduced control.

Step 5 | RFP Induction and Incubation (P2)
  Temperature : 37 C
  Duration    : 4 h (240 min; IR: 14400.0 SECOND)
  Droplets    : 5 daughter droplets actuated to respective assay spots

Step 6 | RFP Fluorescence Detection (P2)
  Plate reader : CLARIOStar (BGM Labtech, Ortenberg, Germany)
  Excitation   : 582 nm; Emission: 612 nm
  Settings     : scan 30x30, width 6 mm, focal height 7.2 mm, gain 2905
  QC gate      : rfpAssay1 (200 uM IPTG, highest expected signal)
  Results      : Dose-response follows sigmoidal (Hill function) profile;
                 max expression at IPTG >= 200 uM; basal levels below 30 uM.
                 Differences in curve steepness vs macroscale attributed to E-field
                 actuation, mixing efficiency, and volume differences between systems.
  Pass (BB5)   : rfpSignal1 > 0 -> dispose all 5 RFP droplets
  Fail (BB6)   : rfpSignal1 <= 0 -> drain all 5 RFP droplets

Step 7 | BGL Culture Growth and Induction - Single-Point (P3A)
  Strains   : BGL1 (T. roseum), BGL2 (T. terrenum), BGL3 (R. marinus)
  Starting OD : 0.4 (triggered by OD monitoring loop from P1)
  IPTG      : 2 uL of 11 mM IPTG mixed with single culture droplet; returned to mixing
              area to uniformly distribute inducer before daughter dispensing.
  Droplets  : 5 daughter droplets per strain (15 total)

Step 8 | Post-Induction Incubation - Single-Point (P3A)
  Temperature : 37 C
  Duration    : 4 h (240 min; IR: 14400.0 SECOND per droplet)
  Total droplets : 15 (5 per strain)

Step 9 | Cell Lysis (P3A)
  Reagent   : 1x lysis buffer, 1.42 uL per droplet
  Temperature : 25 C (room temperature)
  Duration  : 10 min (600 s; IR: 600.0 SECOND)
  Total lysis droplets : 15

Step 10 | MUG Substrate Addition and Incubation - Single-Point (P3A)
  Substrate : 1.42 uL of 6 mM MUG in 150 mM sodium-citrate per droplet
  Temperature : 25 C
  Time points : 0, 15, 30, 45, 60 min
  IR durations : 1.0, 900.0, 1800.0, 2700.0, 3600.0 SECOND
  Note      : t=0 modelled as heat for 1s (no-op compiler token)
  Total assay droplets : 15 (5 time points x 3 strains)

Step 11 | Reaction Stop - Single-Point (P3A)
  Reagent   : 0.4 M glycine-NaOH, 1.42 uL per droplet
  Duration  : 5 s mix
  Total stop droplets : 15

Step 12 | BGL Activity Detection - Single-Point (P3A)
  Plate reader : CLARIOStar
  Excitation   : 368 nm; Emission: 449 nm (MUF fluorescence)
  Settings     : focal height 4.0 mm, gain 664
  QC gates (keyed on t=60 min droplet per strain):
    BGL1 : bgl1Signal; pass BB8, fail BB9, join BB10
    BGL2 : bgl2Signal; pass BB11, fail BB12, join BB13
    BGL3 : bgl3Signal; pass BB14, fail BB15, join BB16
  Results   : BGL3 activity >= 6x BGL1 and BGL2 (rate comparison, Fig 6C).
              BGL1 and BGL2 nearly identical. High BGL3 activity attributed to
              thermostability and salt tolerance of R. marinus enzymes.

Step 13 | BGL3 Multi-Point Induction and Incubation (P3B)
  Strain    : BGL3_Cells (R. marinus DSM4252)
  Starting OD : ~0.1 (low OD; OD monitoring loop bypassed for this subroutine)
  IPTG      : 2 uL of 11 mM IPTG; same volume and concentration as single-point
  Subcultures : 5 daughter droplets induced simultaneously
  Post-induction incubation time points:
    t0h : 0 h  (immediate lysis; 1 s no-op heat token)
    t2h : 2 h  (120 min; IR: 7200.0 SECOND)
    t3h : 3 h  (180 min; IR: 10800.0 SECOND)
    t5h : 5 h  (300 min; IR: 18000.0 SECOND)
    t6h : 6 h  (360 min; IR: 21600.0 SECOND)
  Temperature : 37 C

Step 14 | Cell Lysis - Multi-Point (P3B)
  Reagent   : 1x lysis buffer, 1.42 uL per droplet
  Temperature : 25 C
  Duration  : 10 min (600 s; IR: 600.0 SECOND)
  Total lysis droplets : 5

Step 15 | MUG Substrate Addition and Incubation - Multi-Point (P3B)
  Substrate : 1.42 uL of 6 mM MUG in 150 mM sodium-citrate per droplet
  Temperature : 25 C
  Fixed duration : 30 min for all 5 time points (IR: 1800.0 SECOND each)
  Total assay droplets : 5

Step 16 | Reaction Stop - Multi-Point (P3B)
  Reagent   : 0.4 M glycine-NaOH, 1.42 uL per droplet
  Duration  : 5 s mix
  Total stop droplets : 5

Step 17 | BGL3 Multi-Point Fluorescence Detection (P3B)
  Plate reader : CLARIOStar
  Excitation   : 368 nm; Emission: 449 nm
  Settings     : focal height 4.0 mm, gain 664
  QC gate      : bgl3mpSignal_t6 (6 h; highest expected expression)
  Results      : BGL3 expression at 6 h >= 3x expression at 0 h (Fig 6D).
                 Longer post-induction incubation (>1 h) improves protein folding,
                 accumulation, and productivity in E. coli BL21(DE3). 6 h is optimal.
  Pass (BB17)  : bgl3mpSignal_t6 > 0 -> dispose all 5 MP droplets
  Fail (BB18)  : bgl3mpSignal_t6 <= 0 -> drain all 5 MP droplets
  Terminal     : BB19 disposes all 5 MP QC signals; NOP


BIOSCRIPT COMPILER NOTES
-------------------------
BioScript file : husser_aims_induction_bgl_synbio.bs
Compiler       : lilott8/BioScript (ANTLR4-based, GitHub: https://github.com/lilott8/BioScript)
IR output      : 19 basic blocks (BB1-BB19); 9 if/else gates; 24 CFG edges
DAG            : husser_aims_induction_bgl_synbio_main_dag.dot
Duration units : All durations converted to minutes (m) or seconds (s) for compiler
                 compatibility (BioScript supports s and m only; h token not supported)
                 4 h   -> 240m   (RFP incubation; IR: 14400.0 SECOND)
                 10 min -> 10m   (lysis; IR: 600.0 SECOND)
                 30 min -> 30m   (MUG assay; IR: 1800.0 SECOND)
                 2 h   -> 120m   (BGL3 MP t2h; IR: 7200.0 SECOND)
                 3 h   -> 180m   (BGL3 MP t3h; IR: 10800.0 SECOND)
                 5 h   -> 300m   (BGL3 MP t5h; IR: 18000.0 SECOND)
                 6 h   -> 360m   (BGL3 MP t6h; IR: 21600.0 SECOND)
                 t=0h  -> 1s     (no-op heat token for compiler; IR: 1.0 SECOND)
                 600s  -> 600s   (10 min OD fail branch mixing; IR: 600.0 SECOND)
Modules        : odMeasurement, rfpFluorescenceDetection, bglActivityDetection
No split       : split operation avoided throughout; all dilution series and parallel
                 droplets use explicit dispense + mix scalar variables to prevent
                 stranded-droplet compiler issues (documented in moazami reference file)
drain vs dispose : lilott8 compiler maps both to dispose in IR output; this is expected
                   compiler behaviour, not a source error
Verification   : .bs, .ir, and .dot outputs independently reviewed and confirmed correct
                 (see husser_aims_review.txt for full verification report)
