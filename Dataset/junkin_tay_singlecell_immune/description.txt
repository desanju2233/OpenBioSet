PROTOCOL DESCRIPTION
====================

Title        : Quantitative Multiparameter Measuring of Dynamic Single-Cell Immune Responses
Source Link  : https://q-bio.org/w/images/3/34/Quantitative_multiparameter_measuring_of_dynamic_single-cell_immune_responses.pdf
Paper DOI    : N/A
Journal      : IEEE Engineering in Medicine and Biology Conference (EMBC), 2014
Platform     : Custom PDMS microfluidic device with single-cell trapping chambers,
               microfluidic valve-controlled dynamic stimulus delivery, and
               on-chip bead-based fluorescent sandwich immunoassay


OVERVIEW
--------
This protocol describes a microfluidic platform for dynamic, multiparameter, non-destructive
measurement of immune cell responses at the single-cell level. The system isolates individual
macrophages in distinct trapping chambers, delivers arbitrary temporal stimulus profiles
(brief pulses in seconds to prolonged inputs spanning hours), and simultaneously measures
four functional parameters from the same single cell throughout the experiment:

  1. NF-kB nuclear translocation (real-time transcription factor activation via GFP fusion)
  2. Cytokine and protein secretion (on-chip bead-based fluorescent sandwich assay, multiplexed)
  3. Cell migration (centroid tracking from bright-field time-lapse)
  4. Cell morphology (area, circularity, aspect ratio from bright-field time-lapse)

All four measurements are non-destructive and conducted dynamically on the same single cells.
The resulting large, multiparameter dataset is used to construct predictive models of immune
input-output relationships governing internal and external cellular reactions during an
immune response.

Cell line: RAW264.7 macrophages expressing an NF-kB-GFP fusion reporter protein.
Stimuli:   LPS (brief pulse) and TNF (prolonged exposure), delivered sequentially
           via programmable upstream valve actuation to model physiological stimulus dynamics.


DEVICE ARCHITECTURE
-------------------
Material      : PDMS (polydimethylsiloxane), soft-lithography fabricated
Configuration : Single-cell isolation chambers in a serpentine trapping channel
                integrated with an on-chip bead-based assay zone
Trapping      : Hydrodynamic single-cell trapping with custom trap geometry;
                trapping efficiency verified by bright-field imaging
Flow control  : Upstream microfluidic valves for programmable stimulus switching;
                arbitrary temporal input profiles (seconds to hours)
Imaging       : Inverted fluorescence microscope; time-lapse acquisition every 3-5 min

Measurement channels:
  - GFP (NF-kB reporter): excitation ~488 nm; emission ~510 nm (nuclear translocation)
  - Bead assay fluorescence: multiple spectrally distinct channels (multiplexed cytokines)
  - Bright-field: cell migration centroid tracking and morphology analysis


CELL LINE
---------
RAW264.7 macrophages (murine, ATCC TIB-71) stably expressing NF-kB-GFP fusion protein.
  Culture conditions : DMEM + 10% FBS, 37 C, 5% CO2
  Pre-loading prep   : Single-cell suspension in culture media, ~1e6 cells/mL
  NF-kB reporter     : GFP fused to NF-kB subunit (p65 or p50); cytoplasmic at rest,
                       nuclear upon activation; N/C ratio computed per frame per cell


STIMULI
-------
LPS (Lipopolysaccharide, E. coli):
  Type          : Pathogen-associated molecular pattern (PAMP); TLR4 agonist
  Input profile : Brief pulse (~60 s representative; tunable from seconds to minutes)
  Delivery      : Upstream valve switched to LPS reservoir; flow carries LPS to chambers

TNF (Tumour Necrosis Factor):
  Type          : Pro-inflammatory cytokine; TNFR1/TNFR2 agonist
  Input profile : Prolonged sustained exposure (~60 min representative)
  Delivery      : Upstream valve switched to TNF reservoir after LPS pulse
  Purpose       : Models cytokine-driven NF-kB reactivation (second activation wave)

Sequential LPS -> TNF delivery allows independent characterisation of PAMP-triggered
and cytokine-triggered NF-kB dynamics in the same single cell without destruction.


PROTOCOL STEPS
--------------

Step 1 | Device Priming
  Reagents  : PBS buffer (x2 volumes)
  Operation : Mix and flow through all channels
  Duration  : 5 min (~300 s)
  Purpose   : Removes air bubbles; passivates PDMS channel surfaces to
              minimise non-specific cell adhesion prior to loading.

Step 2 | Hydrodynamic Single-Cell Loading and Trapping
  Cell line     : RAW264.7 macrophages (NF-kB-GFP)
  Concentration : ~1e6 cells/mL in culture media
  Operation     : Flow-through trapping (abstracted as mix in BioScript)
  Duration      : ~2 s (flow event)
  Trap design   : Custom geometry; hydrodynamic resistance routes single cells
                  into isolation chambers; occupied trap blocks second-cell entry
  Notes         : BioScript mix abstracts channel-flow hydrodynamic trapping;
                  no bulk reagent mixing occurs at this step. Trapping efficiency
                  verified by bright-field inspection of chambers.

Step 3 | Channel Wash (Untrapped Cell Removal)
  Reagents  : PBS buffer flush
  Operation : mix (channel-flow wash abstraction)
  Duration  : 30 s
  Purpose   : Removes excess untrapped cells from channels. Only single cells
              retained in trapping chambers proceed to stimulation.

Step 4 | Pre-Stimulus Baseline Imaging
  Operation     : Heat hold at 37 C (standard culture temperature)
  Duration      : 15 min (900 s)
  Readout       : Bright-field and GFP fluorescence images at t=0
  NF-kB state   : Cytoplasmic (inactive baseline)
  Migration ref : Cell centroid coordinates logged (x0, y0)
  Morphology ref: Area, circularity, aspect ratio at t=0

Step 5 | LPS Stimulus Delivery (Brief Pulse)
  Reagents      : LPS_Stimulus
  Operation     : mix (valve-controlled flow switching; LPS pulse to chambers)
  Duration      : 60 s (representative short pulse; tunable)
  Profile       : Brief pulse -- seconds-range input
  Receptor      : TLR4 on RAW264.7 surface
  Expected resp : Rapid NF-kB nuclear translocation within 10-15 min post-stimulus

Step 6 | TNF Stimulus Delivery (Prolonged Exposure)
  Reagents      : TNF_Stimulus
  Operation     : mix (valve-controlled flow switching; TNF flow to chambers)
  Duration      : 60 min (3600 s)
  Profile       : Sustained prolonged input
  Receptor      : TNFR1/TNFR2
  Expected resp : Second wave of NF-kB activation; oscillatory dynamics possible

Step 7 | Dynamic NF-kB Imaging and Multiparameter Observation
  Operation         : Heat at 37 C (imaging window) + detect nfkbActivationDetection
  Imaging duration  : 4 h (240 min; 14400 s modelled as heat hold)
  Detection duration: 5 min (300 s)
  Detection module  : nfkbActivationDetection
  Imaging interval  : Every 3-5 min (time-lapse)
  NF-kB readout     : Nuclear/cytoplasmic GFP ratio per cell per frame
  Co-measurements   : Migration vectors (centroid tracking, same frames)
                      Morphology descriptors (area, circularity, aspect ratio, same frames)
  Nature            : Non-destructive; cells remain viable throughout
  Module abstracts  : Fluorescence acquisition, nuclear mask segmentation,
                      N/C ratio computation, migration vector extraction,
                      morphology descriptor calculation

  QC gate (NF-kB):
    Pass (nfkbSignal > 0)  : NF-kB nuclear translocation detected; proceed to secretion assay
    Fail (nfkbSignal <= 0) : No activation detected; drain stimulated droplet

Step 8 | Periodic Conditioned Medium Sampling
  Reagents         : CultureMedia (fresh)
  Operation        : mix (medium exchange + supernatant collection)
  Sampling interval: Every 30-60 min throughout stimulation window
  Sample volume    : ~50 nL per time point
  Duration         : 30 s per exchange event
  Non-destructive  : Fresh media returned after each sample; cells remain viable
  Purpose          : Captures time-resolved secretion data matched to NF-kB and
                     migration traces of the same single cell

Step 9 | On-Chip Bead-Based Cytokine Capture
  Reagents          : BeadConjugatedAntibody, conditioned medium sample
  Operation         : mix + heat at 25 C
  Incubation        : 60 min (3600 s) at room temperature (25 C)
  Bead type         : Antibody-conjugated capture beads; spectrally distinct per cytokine
  Targets           : TNF, IL-6, MCP-1, and other secreted proteins (multiplexed)
  Configuration     : On-chip assay zone; no off-chip transfer required
  Notes             : Sandwich complex forms on bead surface; multiple cytokines captured
                      simultaneously from the same ~50 nL sample volume.

Step 10 | Detection Antibody Addition (Sandwich Completion)
  Reagents   : FluorescentSandwichReagent (fluorescent secondary antibody)
  Operation  : mix + heat at 25 C
  Incubation : 30 min (1800 s) at room temperature
  Readout    : Fluorescence intensity per bead cluster proportional to
               secreted protein concentration (quantitative vs. standard curve)
  Targets    : Same multiplexed panel as Step 9

Step 11 | Bead Assay Wash
  Reagents   : WashBuffer
  Operation  : mix
  Duration   : 5 min (300 s)
  Purpose    : Removes excess unbound fluorescent detection antibody;
               reduces background signal to enable quantification at
               single-cell secretion levels (pM to nM range)

Step 12 | Fluorescence Detection of Cytokine Secretion
  Operation         : detect cytokineSecretionDetection
  Detection duration: 60 s
  Detection module  : cytokineSecretionDetection
  Module abstracts  : Bead cluster fluorescence acquisition, bead segmentation,
                      per-channel intensity quantification, multi-cytokine spectral
                      demultiplexing, concentration calibration against standard curve
  Output            : Quantitative secreted protein levels per single cell per time point
  Dynamic range     : pM to nM

  QC gate (Secretion):
    Pass (secretionSignal > 0)  : Cytokine signal above detection threshold; dispose assay
    Fail (secretionSignal <= 0) : Signal below LOD or assay failure; drain


MULTIPARAMETER DATASET
----------------------
Each single-cell experiment yields four co-registered time series:

  Parameter          | Method                  | Temporal Resolution | Nature
  -------------------|-------------------------|---------------------|--------------------
  NF-kB activation   | Nuclear/cytoplasmic GFP | 3-5 min             | Non-destructive
  Cytokine secretion | On-chip bead assay      | 30-60 min           | Non-destructive
  Migration          | Centroid tracking       | 3-5 min             | Non-destructive
  Morphology         | Image analysis          | 3-5 min             | Non-destructive

Dataset is used to construct predictive models of immune input-output relationships,
accurately depicting the overall system of cellular reactions during an immune response.

-------------------------

IR output       : 7 basic blocks (BB1-BB7), 2 if/else gates, 8 CFG edges
DAG file        : junkin_tay_singlecell_immune_main_dag.dot
Duration units  : All durations converted to seconds (s) or minutes (m) for compiler
                  compatibility (BioScript supports s and m only; h token not supported)
                  4 h imaging window  -> 240m  (IR: 14400.0 SECOND)
                  60 min bead capture -> 60m   (IR: 3600.0 SECOND)
                  30 min detection Ab -> 30m   (IR: 1800.0 SECOND)
                  5 min bead wash     -> 5m    (IR: 300.0 SECOND)
                  15 min baseline     -> 15m   (IR: 900.0 SECOND)
Modules         : nfkbActivationDetection
                  cytokineSecretionDetection
                  migrationMorphologyDetection
Trapping note   : mix statements in Steps 2 and 3 abstract hydrodynamic single-cell
                  trapping and channel-flow wash events (not DMF electrode mixing).
Heat note       : heat statements model 37 C culture-temperature incubation (baseline,
                  imaging window) and 25 C room-temperature bead assay incubations.
ASCII note      : All comment text restricted to ASCII characters. ANTLR4 FileStream
                  reads .bs files as ASCII; non-ASCII characters (e.g. diacritics such
                  as in "Savas" or "Zurich") cause UnicodeDecodeError at compile time
                  and must be replaced with ASCII equivalents before compilation.
CFG structure   : BB1 (main/entry) -> BB2/BB3 (NF-kB gate) -> BB4 (join) ->
                  BB5/BB6 (secretion gate) -> BB7 (terminal/NOP)
