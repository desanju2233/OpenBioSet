PROTOCOL DESCRIPTION
====================

Title        : A Microfluidic DNA Library Preparation Platform for Next-Generation Sequencing
Source Link  : https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0068988&type=printable
Paper DOI    : https://doi.org/10.1371/journal.pone.0068988
Journal      : PLoS ONE, 2013, Vol. 8, Issue 7, Article e68988
Platform     : DMF hub with peripheral capillary-based modules (digital microfluidics +
               continuous-flow off-chip sample preparation modules)


OVERVIEW
--------
This protocol describes a fully integrated and automated microfluidic system for preparing
Illumina sequencer-ready NGS libraries from nanogram-scale genomic DNA samples. The platform
combines a central digital microfluidic (DMF) hub -- a planar, Teflon-AF-coated ITO electrode
array that actuates discrete droplets via electrowetting -- with peripheral continuous-flow
capillary-based modules that perform each of the four unit operations in the Nextera library
preparation workflow: DNA tagmentation, magnetic bead-based clean-up, limited-cycle PCR, and
two-stage size selection.

The DMF hub serves as a "fluidic router": it meters reagents, routes droplets between
peripheral modules via in-plane fused-silica capillaries, and integrates all sample
preparation steps into a single, hands-free, programmable protocol. Off-DMF modules are
individually optimised for their respective unit operations, allowing reliable thermocycling,
magnetic bead manipulation, and precise size selection that would be difficult to implement
on the DMF surface alone.

The platform was validated with human genomic DNA, Escherichia coli MG1655 gDNA (5 ng input),
and Klebsiella pneumoniae BAA-2146 (KpnNDM) gDNA. E. coli libraries yielded >99% alignment
to the reference genome, even genome coverage, and mean depth of 168-320X across three
replicates. De novo assembly of KpnNDM revealed at least five beta-lactamase genes including
NDM-1. The protocol reduces hands-on time to ~5 min and total preparation time to ~1 h,
using ~30 uL total reagent volume (vs. 80-650 uL conventional).


DEVICE ARCHITECTURE
-------------------
Hub type : Central DMF hub; two gap configurations:
             185 um gap (human gDNA; 1-2 uL droplet volumes)
             400 um gap (bacterial gDNA; 2X volumes)

Bottom plate : ITO-patterned glass (photolithography + etching); coated with 4 um Parylene-C
               + 50 nm Teflon-AF (spin-coated 1% wt/wt Fluorinert FC-40, 2000 rpm, 60 s;
               post-baked at 160 C, 10 min). 48 actuation electrodes: 44 rectangular
               (~2.5 x 2.5 mm and ~6.3 x 9.5 mm), 4 pentagon-shaped (~4.5 x 7.5 x 6.3 mm);
               inter-electrode gap 20 um.
Top plate    : Unpatterned ITO glass; 50 nm Teflon-AF.
Manifold     : Custom-engineered polymer manifold frame with metal compression frames;
               spring-loaded pogo-pin electrical contacts; CapTite fittings.

Capillary interface:
  14 side ports; fused-silica capillaries (Polymicro) coated in-house with Teflon-AF.
  185 um gap:  160/100 um OD/ID capillaries (Part TSU100170); tip ~250 um from
               2.5 x 2.5 mm receiving electrodes.
  400 um gap:  360/100 um OD/ID capillaries (Part TSU100375); directly inserted.
  Module tubing: 750/562 um OD/ID polycarbonate (Part CT562-750-5, Paradigm Optics).
  Short coupling tubes: 500/167 um OD/ID (Part CT250-500-5); glued with optical cement.
  Pumping:     8-port valve manifold syringe pump (Part 59943-01, Hamilton, Reno NV);
               positive displacement; 10 uL/min flow rate. 1-2 uL air gap separates
               reagent bolus from pumping water.

Peripheral modules:
  Tagmentation   : Thermal module; 750 um OD tubing in ~850 x 800 um (D x W) groove in
                   custom-machined Al block; module recessed ~100 um below block surface
                   for temperature match within ~5 C. Closed-loop PID TEC.
  Limited-cycle PCR : Same Al block configuration; OpenPCR benchtop cycler (Saratoga CA).
  Clean-up       : Capillary tube module; external neodymium magnet (3 mm dia x 3 mm,
                   K&J Magnetics, Jamison PA); positive pressure-driven syringe pump for
                   near-complete supernatant removal; bolus shuttle resuspension.
  Size selection : Same magnet/pump configuration as clean-up; two-stage bead:DNA ratio
                   protocol (2.2 uL and 0.45 uL SPRI beads for Stages 1 and 2).
  Waste          : Dedicated waste capillary and reservoir.

Actuation: 80-90 V_rms at 15 kHz generated by function generator (Trek, Medina NY) amplified
           by Digi-Key Corporation (Thief River Falls MN). Computer-controlled electronic
           interface via manual keystrokes or preprogrammed scripts. Droplets visualised with
           MVX10 microscope (Olympus) + QIClick camera (Qimaging); Streampix5 (Norpix) for
           video capture.


REAGENTS
--------
Carrier fluid      : Fluorinert FC-40 (Sigma Chemical, St. Louis MO)
Pluronic additive  : Pluronic F127 (Sigma Chemical); 0.1% w/v in all DNA and reagent solutions.
                     Added to prevent biofouling (protein/enzyme adsorption to Teflon-AF).
                     Validated not to affect Nextera tagmentation efficiency (Fig S1, paper).
Buffer             : 1X Tris-EDTA (TE) pH 8.0 (Sigma Chemical)
Nextera enzyme mix : Nextera DNA Sample Preparation Kit (Illumina, San Diego CA)
                     On-chip mixture: 2 uL High Molecular Weight + 0.5 uL enzyme mix + 0.1% F127
PCR mixture        : 12.5 uL 2X PCR buffer + 0.5 uL primer cocktail + 0.5 uL PCR enzyme
                     + 0.5 uL 50X Adapter 2 (Nextera kit); scaled to 2.8 uL on-chip volume
SPRI beads         : Solid Phase Reversible Immobilisation beads (Beckman Coulter, Danvers MA)
Wash solvent       : Ethanol (HPLC-grade organic solvent)
Elution buffer     : Water + 0.1% Pluronic F127 w/v
Decontamination    : 10% v/v bleach then deionized water rinse between library runs


PROTOCOL STEPS
--------------

Step 1 | gDNA Sample Dispensing and Nextera Enzyme Mixing
  Reagents        : GenomicDNA (1.8 uL at 5 ng/uL in TE + 0.1% F127); NexteraEnzymeMix (0.6 uL)
  Operation       : Dispense both droplets from pre-loaded capillaries onto 185 um-gap DMF hub;
                    actuate together; mix by continuous aspiration in and out of capillary for 30 s
                    at room temperature (80-90 V_rms, 15 kHz)
  Duration        : 30 s mixing
  Notes           : Bacterial gDNA runs use 400 um-gap hub with 2X volumes of all reagents.

Step 2 | Tagmentation
  Reagents        : tagmentationMix
  Operation       : Aspirate into tagmentation thermal module; incubate at 55 C for 5 min
  Temperature     : 55 C
  Duration        : 5 min (300 s)
  Module          : Tagmentation Al block (closed-loop PID TEC; temperature match within ~5 C)
  Product         : Adapter-tagged DNA fragments; broad 150-1000 bp distribution (Fig 4b);
                    adapter dimers ~45 bp also generated; removed in Step 3
  Notes           : Transposase simultaneously fragments and tags gDNA (Nextera transposition
                    reaction). No mechanical fragmentation or end-repair required.

Step 3 | Magnetic Bead Clean-up -- Capture and Supernatant Removal
  Reagents        : tagmentedProduct; MagneticBeads_SPRI (4.5 uL)
  Operation       : Merge on DMF hub (30 s); aspirate combined droplet into clean-up module;
                    apply external neodymium magnet; immobilise bead pellet on inner tube wall;
                    positive pressure-driven flow removes supernatant; supernatant returned to
                    DMF hub and actuated to waste capillary
  Duration        : 30 s mixing
  Supernatant removed: Excess enzyme, adapter dimers, small DNA fragments
  Notes           : Near-complete supernatant removal achieved by positive pressure-driven syringe
                    pump flow (vs. conventional DMF magnet actuation). Bead pellet not on DMF
                    surface -- preserves Teflon-AF coating (Fig 3, paper).

Step 4 | Ethanol Wash of Bead Pellet (x3)
  Reagents        : EthanolWash (3.0 uL per cycle)
  Operation       : Dispense fresh ethanol droplet onto DMF hub; aspirate into clean-up module;
                    shuttle bolus back-and-forth across immobilised bead pellet for 30 s;
                    return ethanol to DMF hub; actuate to waste module; aspirate off-chip.
                    Repeat for 3 wash cycles total
  Duration        : 30 s per wash cycle; 3 cycles
  Notes           : Chaotic back-and-forth mixing enhances contaminant removal. Each wash
                    uses a fresh 3 uL ethanol droplet dispensed independently.

Step 5 | Elution of Purified Tagmented DNA
  Reagents        : ElutionBuffer (2.2 uL)
  Operation       : Dispense elution buffer onto DMF hub; aspirate into clean-up module;
                    remove external magnet; shuttle bolus for 30 s to resuspend bead pellet;
                    re-apply magnet to immobilise beads; return DNA-containing eluate to DMF hub;
                    actuate to PCR inlet electrode
  Duration        : 30 s resuspension
  Temperature     : Room temperature
  Product         : 2.2 uL purified adapter-tagged DNA fragments (excess enzyme and adapter
                    dimers removed)

Step 6 | PCR Mixture Dispensing and Merging with Eluate
  Reagents        : cleanedDNA (2.2 uL); PCRMixture (2.8 uL)
  Operation       : Dispense PCR Mixture from capillary onto DMF hub; merge with eluate (30 s);
                    aspirate 2.8 uL combined droplet into PCR thermal module inlet;
                    remaining 2.2 uL actuated to waste
  Duration        : 30 s mixing

Step 7 | Limited-Cycle PCR -- Adapter Addition and Library Enrichment
  Reagents        : prePCRDroplet (2.8 uL in PCR module)
  Operation       : Thermocycling in PCR module (Al block, OpenPCR cycler, closed-loop PID TEC)
  PCR conditions  :
    Initial extension  : 72 C for 3 min
    Denaturation       : 95 C for 30 s
    10 cycles          :
      Denaturation     : 95 C for 10 s
      Annealing        : 62 C for 30 s
      Extension        : 72 C for 3 min
    Note: 9 cycles for bacterial gDNA (400 um gap hub)
  Product         : Enriched library ~200-10000 bp; Illumina-specific dual-indexed sequencing
                    adapters incorporated; primer dimers ~55 bp present (removed by size selection)
                    (Fig 4c)
  Notes           : PCR reaction mixture (2.8 uL) cycled in module. After completion, product
                    dispensed back onto DMF hub for size selection.

Step 8 | Size Selection Stage 1 -- Removal of Fragments <200 bp
  Reagents        : prePCRDroplet; MagneticBeads_SPRI (2.2 uL)
  Operation       : Merge PCR product with SPRI beads on DMF hub (30 s); aspirate into
                    size-selection module; apply magnet; immobilise beads;
                    return supernatant to DMF hub
  Bead ratio      : High bead:DNA ratio (binds all DNA fragments including primer dimers
                    and small fragments <200 bp onto beads)
  Supernatant     : Contains desired 200-400 bp library fragments in solution at this ratio
  Notes           : The supernatant -- not the bead-bound fraction -- carries the size-selected
                    library at Stage 1. Bead pellet (small DNA, primer dimers) disposed.

Step 9 | Size Selection Stage 2 -- Removal of Fragments >400 bp
  Reagents        : librarySuper; MagneticBeads_SPRI (0.45 uL); EthanolWash; ElutionBuffer
  Operation       : Merge Stage 1 supernatant with low-volume SPRI beads (30 s); aspirate into
                    size-selection module; apply magnet; immobilise beads containing 200-400 bp
                    library; ethanol wash bead pellet; elute final library (3 uL EB; 5 uL for
                    bacterial gDNA); return eluate to DMF hub as final sequencer-ready library
  Bead ratio      : Low bead:DNA ratio (captures only large fragments >400 bp; desired
                    200-400 bp library bound to pellet after Stage 1 supernatant binds)
  Product         : Final sequencer-ready DNA library; target size distribution 200-400 bp
                    (Fig 4d); small broad hump at high MW indicates trace single-stranded products
  Notes           : At Stage 2 the desired 200-400 bp library IS bead-bound; large fragments
                    remain in solution and are disposed. Final library eluted into 3 uL (human)
                    or 5 uL (bacterial) elution buffer and dispensed to DMF hub.

Step 10 | Library QC Detection and Off-chip Sequencing
  Reagents        : dnaLibrary (3 uL)
  Operation       : detect libraryQC on dnaLibrary for 30 s
  Detection module: libraryQC (abstracts Bioanalyzer size distribution check + Kapa quant)
  Off-chip QC     :
    Size distribution : Bioanalyzer (Agilent); target peak 200-400 bp (Fig 4d)
    Quantitation      : Kapa Library Quantification Kit (KAPA Biosystems, Woburn MA)
    Loading conc.     : 8 pM on MiSeq; primary variability source is ~1000X dilution step
    Sequencing kit    : 300-cycle paired-end 150 bp MiSeq kit (Illumina)
    Read archive      : NCBI SRA accession SAMN02152539 (E. coli); APNN00000000.1 (K. pneumoniae)
  Branch          :
    Pass (BB2)    : librarySignal > 0 -> valid 200-400 bp library at sequencer-compatible
                    concentration; dispose for off-chip MiSeq loading
    Fail (BB3)    : librarySignal <= 0 -> failed library preparation; drain


SEQUENCING RESULTS (E. coli MG1655, 3 replicates)
--------------------------------------------------
Instrument      : Illumina MiSeq (in-house); 300-cycle paired-end 150 bp kit; 8 pM loading
Total bases     : 1.1 GB, 0.7 GB, 1.3 GB
Total reads     : 9.7M, 6.5M, 10.8M
Mean coverage   : 249X, 168X, 320X
Reads mapped    : 99.4%, 99.2%, 99.7% (reference: NC_000913.2; aligner: bowtie2)
GC content      : 50.1%, 49.7%, 50.1%
Coverage        : Even across entire ~4.6 kb E. coli genome; no significant spikes or drops (Fig 5)
De novo assembly: Velvet v1.2.03; k values tested: 25, 27, 29; contig cutoff 200 bp
                  Mean contig count: 249 +/- 27; Mean N50: 62.1 +/- 18.2 kbp

K. pneumoniae BAA-2146 (KpnNDM) de novo assembly:
  1384 contigs; N50 12.4 kbp; expected genome ~5.8 Mbp; GC ~57%
  Findings: multiple plasmids; small high-copy plasmid fully assembled;
            >=5 beta-lactamase genes including NDM-1 (carbapenem resistance);
            large number of transposable elements. Accession: APNN00000000.1


BIOSCRIPT COMPILER NOTES
-------------------------
BioScript file  : kim2013_ngs_library_prep_dmf.bs
Compiler        : lilott8/BioScript (ANTLR4-based)
IR output       : 4 basic blocks (BB1-BB4); 1 if/else gate; 4 CFG edges
DAG             : kim2013_ngs_library_prep_dmf_main_dag.dot
                  Diamond CFG: main -> (bsbbif_2_t | bsbbif_3_f) -> bsbbif_4_j
Duration units  : All durations in s (seconds) or m (minutes); h token not supported.
                  5 min tagmentation    -> 5m  (IR: 300.0 SECOND)
                  3 min PCR extension   -> 3m  (IR: 180.0 SECOND)
                  10-cycle PCR block    -> 2200s (10 cycles x 220s per cycle; IR: 2200.0 SECOND)
Modules         : libraryQC, sequencerReadyDetection
Manifests       : GenomicDNA, NexteraEnzymeMix, PCRMixture, MagneticBeads_SPRI,
                  EthanolWash, ElutionBuffer, PluronicF127, FC40_Oil
Compiler notes  : drain in BioScript source (fail branch) is normalised to dispose in IR
                  by the lilott8 backend -- this is a known compiler behaviour, not a source bug.
                  All mix operations use scalar droplet variables (no array indexing) to maintain
                  compatibility with the lilott8/BioScript compiler constraint documented in the
                  moazami reference file.
Biological scope: This .bs file encodes the 185 um-gap hub protocol for human gDNA.
                  Bacterial gDNA (400 um gap, 2X volumes, 9 PCR cycles, 5 uL final elution)
                  requires parameter adjustment; same CFG structure applies.
